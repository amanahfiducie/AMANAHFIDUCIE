# AMANAHFIDUCIE

Site web **AMANAH FIDUCIE** (SOFIGEPAM) — fiducie islamique au Sénégal.

## Déploiement Vercel

Importer le dépôt sur [Vercel](https://vercel.com/new) : **Build** `npm run build`, **Install** `npm install`. La variable `VERCEL=1` active Nitro (preset `vercel`) ; sans elle, le build cible Cloudflare (`dist/` + Wrangler).
